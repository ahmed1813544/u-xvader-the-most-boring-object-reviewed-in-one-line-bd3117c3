Entry for the [make.fun bounty "The Most Boring Object, Reviewed in One Line"](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3).

`main.py` (stdlib only, no network) writes a single-line review of the
dullest everyday object — a rubber band — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`:

> The rubber band: holds everything together for months, then snaps the
> moment you finally trust it — a tiny, passive-aggressive explosion.

The joke comes from how the object really behaves: a rubber band holds
things together for ages, then snaps without warning the moment you rely
on it.

Run it with `python3 -P -s main.py` (the grader sets `MAKEFUN_OUTPUT_DIR`).
